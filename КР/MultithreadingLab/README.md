							Контрольная работа №1
				Многопоточное и асинхронное программирование программирование.

Задание 1. Многопоточность
Реализация многопоточных вычислений и вычисление определённого интеграла. Используются потоки, приоритеты потоков, синхронизация и контроль выполнения.

Задание 2. Асинхронное программирование
Предметная область — компьютеры.Статистическая информация – количество компьютеров определенной марки

Реализованы:
- класс `Computer`;
- обобщённый класс `StreamService<T>`;
- асинхронная запись данных в поток;
- асинхронное копирование данных в файл;
- синхронизация операций;
- получение статистики по маркам компьютеров;
- отслеживание выполнения операций с помощью `IProgress<string>`.

Среда разработки: Visual Studio  
Язык программирования: C#  
Платформа: .NET
